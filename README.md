# Rota PMMG 2027

Aplicativo web instalável (PWA) para organizar os estudos e o TAF da PMMG 2027.

## Publicação no GitHub Pages
1. Envie todos os arquivos deste pacote para a raiz do repositório.
2. Vá em Settings > Pages.
3. Escolha Deploy from a branch.
4. Selecione main e /(root).
5. Salve.

## Instalação no iPhone
1. Abra o endereço publicado no Safari.
2. Toque em Compartilhar.
3. Selecione Adicionar à Tela de Início.

## Recursos
- Dashboard e metas
- Plano semanal
- Disciplinas e módulos
- Cronômetro
- Controle de questões
- Revisões
- TAF
- Tema claro/escuro
- Funcionamento offline básico
